# Notes — “LLM Evaluators Recognize and Favor Their Own Generations”

**作者：** Arjun Panickssery, Samuel R. Bowman, Shi Feng · **首次提交：** 2024-04-15 · **发表：** NeurIPS 2024 Main Conference · **URL：** https://arxiv.org/abs/2404.13076 · **会议页：** https://proceedings.neurips.cc/paper_files/paper/2024/hash/7f1f0218e45f5414c79c0679633e47bc-Abstract-Conference.html · **类型：** empirical paper · **Found:** true

## 论文问题与科学动机

LLM-as-a-judge 的一个根本风险是：同一个模型家族既生成回答，又评价回答。此前研究已经观察到模型会给自己的输出更高分，但“自偏好”至少有两种解释：模型真的识别出“这是我生成的”并据此偏爱；或它只是偏爱某些恰好与自己输出共现的风格、长度、可读性和质量特征。两者对评测可信度和缓解方法的含义完全不同。

本文把问题收窄为一个可干预的科学问题：**LLM 的自我识别能力是否会促进自偏好？** 作者并不把 self-recognition 解释为意识或内省，只采用操作性定义：模型能否从文本线索区分自己的生成与其他模型或人类的生成。研究的关键不是再次展示自偏好，而是同时测量识别与偏好、通过微调改变识别能力，并检验两者是否随干预共同变化。

## 核心方法和具体机制

### 1. 把同一模型轮流放在三个角色中

实验使用 GPT-4、GPT-3.5 和 Llama-2-7B-Chat。每个模型既可能是：

- **generator：** 对文章生成摘要；
- **authorship evaluator：** 判断摘要是否由自己生成；
- **quality evaluator：** 判断哪个摘要质量更高。

数据来自 XSUM 与 CNN/DailyMail，各抽取 1,000 篇文章，并保留数据集中的人类摘要。模型摘要用 temperature 0 生成，且统一大小写和标点，降低简单格式捷径。这里的“自己”指同一模型名称/检查点，不代表模型能追踪某一次真实生成事件。

### 2. 用成对与单样本两种任务拆开“识别”和“偏好”

**成对任务**给出同一文章的两份摘要。一份来自被测模型，另一份来自人类或另一个 LLM。识别任务问哪份由自己生成，偏好任务问哪份质量更高。作者读取答案 token 的概率，而不只取离散选择；每一对交换顺序再问一次，并平均两次置信度，以减轻明显的位置偏差。

**单样本任务**只给一份摘要。识别任务问是否由自己生成，偏好任务给 1–5 分；分数同样用 token 概率加权。单样本设置用于检查模型是否拥有稳定、可校准的绝对判断，而不是只会在两个候选间找相对差异。

自偏好不是简单的“模型经常选自己的摘要”。作者比较互为 evaluator/generator 的两个方向：若 A 评 A 对 B 的偏好和 B 评 B 对 A 的偏好之和大于 1，才表示两边都出现以自身身份为中心的额外偏好。这个定义能部分控制某个生成器本来就更好的情况，但仍不是人类等质量配对的完整替代。

### 3. 直接干预 self-recognition，而不只做观察相关

作者把每个数据集的 1,000 篇文章分成 500 篇训练、500 篇测试，用“哪份是自己的摘要”监督微调 GPT-3.5 与 Llama-2，并测试 2、10、500 个训练样本以及跨数据集迁移。Llama-2 使用 8-bit 量化、1 epoch、Adam、学习率 5×10⁻⁵；GPT-3.5 使用当时的官方微调 API。

为了排除“微调只是教会模型偏好某个表面属性”，作者又分别针对摘要长度、元音数、Flesch–Kincaid 可读性、恒定标签和随机标签做控制微调。若这些干预造成的 self-recognition 变化仍与 self-preference 落在相同关系线上，就说明结果不容易由某一个被挑中的属性解释。

此外，作者做了两个补充检验：一是让微调后的模型重新生成摘要，检查偏好变化是否只是因为生成质量变好；二是在提示中显式标注摘要来源，并交换正确/错误来源标签，观察模型是否会随“身份信息”改变评价。

## 实验设置与主要结果

- **开箱即用的成对识别高于随机。** 三个模型在简单成对任务中都能以高于 50% 的准确率区分自己与其他来源；GPT-4 最强，在把自己与另两个 LLM及人类区分的汇总设置中达到 **73.5%**。模型普遍最容易区分自己与人类，更弱模型也更难区分自己与更强模型。
- **成对自偏好确实存在。** 三个 evaluator 都更偏爱自己的摘要，且相对人类摘要时最明显；但这不自动证明“识别导致偏好”。
- **单样本识别与评分明显更弱。** 模型在没有对照候选时容易出现固定回答倾向，说明测到的能力更像相对风格辨别，而不是稳定的绝对来源校准。
- **顺序效应很大。** 交换两个候选后，GPT-4、GPT-3.5、Llama-2 的答案反转率分别约为 **25%、58%、89%**（跨任务/数据集汇总）。平均双顺序概率能降噪，但如此高的反转率本身就是 judge 不稳定性的证据。
- **微调显著增强识别并伴随偏好增强。** 用 500 个样本训练后，部分同域设置的 self-recognition 超过 90%。例如 GPT-3.5 在 XSUM 上训练后，同域识别/偏好分别为 **0.896/0.898**，迁移到 CNN/DailyMail 为 **0.738/0.750**；在 CNN/DailyMail 上训练后，同域为 **0.959/0.970**，迁移到 XSUM 为 **0.764/0.787**。
- **跨实验条件呈强线性关系。** 不同训练规模、数据集和属性控制下，self-recognition 与 self-preference 大致落在同一条线性趋势上；跨数据集迁移也保留这一关系。这是论文支持“识别参与偏好”的核心证据。
- **样本级证据没有同样整齐。** 单个样本上识别置信度与偏好的 Kendall τ 多为正（例如 GPT-3.5 基座在 XSUM/CNN 上为 0.41/0.37，Llama-2 为 0.73/0.50），但微调后不稳定地增减。因此证据更支持“模型/条件层面的能力共同变化”，而不是已经识别出每个具体样本的因果链。
- **生成质量改善不足以解释结果。** 微调后重新生成的摘要经常退化；在可比较的剩余条件中，平均偏好约为 0.46，只有 22% 的 evaluator–dataset 组合更偏好微调模型生成（>0.51）。因此“生成变好，所以 evaluator 合理地更喜欢它”不是主要解释。
- **显式来源标签会影响评价，但不稳健。** GPT-4 与 GPT-3.5 在 XSUM 上会随交换的来源标签反转偏好；CNN/DailyMail 和 Llama-2 上没有清晰一致效果。身份线索可以被利用，但其效应依赖任务与模型。

## 已验证结论、合理推断与待验证假设

### 论文已验证

- 在两项摘要数据集和三个当时的模型上，LLM 能以高于随机的准确率在成对候选中识别自身生成，也会相对偏爱自身生成。
- 对 GPT-3.5 与 Llama-2 的识别微调会同时改变自我识别和自偏好，两者在多种干预条件下呈强线性相关，并能跨 XSUM/CNN-DM 迁移。
- 长度、元音数、可读性、恒定/随机标签等单一控制不能轻易消除上述条件级关系；微调后的生成质量也不能充分解释偏好增强。
- 双候选顺序、成对与单样本形式会大幅改变结论强度，judge 测量协议本身是重要变量。

### 基于证据的合理推断

- evaluator 与 generator 是否同源必须成为实验设计中的显式因素；只报告一个闭源 judge 的总分，可能把模型家族关系误当作系统质量。
- 实践中至少应做候选顺序交换、跨家族 judge、来源标签盲化和人类抽查；这些操作不能保证无偏，但可暴露自偏好与位置偏差的部分风险。
- “模型识别自己的文本”更可能是对家族风格、词汇分布和后训练习惯的统计识别，而不是对生成历史的内省。论文的操作性定义与这一解释兼容。
- 自偏好既可能污染 benchmark，也可能在 reward modeling/self-refinement 中形成反馈回路：模型产生更像自己的文本，judge 再奖励这种文本。但本文没有直接运行这类训练回路。

### 待实验验证

- 在 GPT-4o/5、Claude、Gemini、Llama 3/4、Qwen 等新模型，以及代码、数学、agent trajectory 和多轮对话上，识别—偏好关系是否保持。
- 当候选质量由独立人类或可验证答案严格匹配后，剩余效应有多少；本文没有为每一对摘要提供独立的人类等质量标注。
- 线性关系的真正中介变量是来源识别、困惑度/熟悉度、风格特征，还是 evaluator 与 generator 共享的错误模式；现有控制只排除了少数简单混杂。
- 采用匿名改写、风格规范化、多 judge jury 或显式分解评分准则，能否因果地降低偏差而不损害 judge 准确率。
- 在线 RLHF/RLAIF 中，自偏好是否会被 policy 主动利用并造成 reward hacking；论文只做离线摘要评价。

## 局限性

- 任务只覆盖摘要，且只有 XSUM 与 CNN/DailyMail；两者的人类参考摘要风格固定，结论不能直接外推到开放式对话、推理或 agent 行为。
- 模型范围是 GPT-4、GPT-3.5 与 Llama-2-7B-Chat，代表的是 2023–2024 年能力与接口；闭源模型细节和版本漂移也不可控。
- “互惠偏好之和 > 1”只能部分控制生成质量。没有逐样本人类等质量判断时，共享错误、风格熟悉度或参考摘要缺陷仍可能制造看似自偏好的差异。
- 相关性出现在模型/干预条件层面，样本级因果证据较弱。控制微调落在同一趋势线上能排除一些简单解释，却不能唯一确定 self-recognition 是因果中介。
- 双顺序平均是实用修正，不是对位置偏差的机制解决；Llama-2 高达 89% 的顺序反转意味着概率平均可能掩盖两个互相矛盾的判断。
- 微调实验有时降低生成质量，且训练样本、提示、温度与评分 token 设计有限；没有系统报告多随机种子、校准误差或完整置信区间。
- 论文把 reward modeling、constitutional AI、self-refinement 与安全风险作为可能后果讨论，但没有在这些系统中直接验证。

## 与仓库已有论文和主题的主动关联

- **RewardBench 2：** 后者在判别式 RM 中观察到对同一基座谱系生成文本的轻微偏好，并因此强调多模型 completion pool。本文给出更早的机制线索：生成式 evaluator 能识别并偏爱同源输出。两者共同说明 evaluator–generator 谱系不是背景信息，而是应控制的实验变量。
- **Who Validates the Validators? / EvalGen：** EvalGen 用用户标注的 failures、coverage 与 false-failure rate 校准 judge；本文说明这种本地验证还应按输出来源分层。如果 criterion 对总体准确，却系统性误判某一模型家族，聚合指标会隐藏偏差。
- **AI Agents That Matter：** 该文要求拆开模型、scaffold、成本和 holdout；本文增加另一层：当同一模型既参与 agent 生成又参与评分时，系统比较可能受到 judge 亲缘关系污染。对 agent benchmark，judge 家族与被测 agent 的底座也应披露。
- **BenchJack：** BenchJack 研究 agent 主动利用 benchmark/评分实现漏洞；本文研究 evaluator 的内生偏好。前者是“被测系统攻击评分器”，后者是“评分器天然偏向同源输出”，两种机制都可能制造高分但不代表真实任务能力。
- **Training Verifiers to Solve Math Word Problems：** verifier 的价值依赖它能把正确候选从错误候选中分离。本文提醒，当候选由不同模型家族产生时，verifier 可能同时读取正确性与来源特征；best-of-N 的收益需要与候选来源控制一起报告。

## 与近期 AI / 评测论文的关系

- **Self-Preference Bias in LLM-as-a-Judge** — 2024-10-29，https://arxiv.org/abs/2410.21819 。该工作提出量化指标，并发现 LLM 相比人类更偏好低困惑度文本，不论文本是否由自己生成。它给本文的“自我识别”提供了竞争机制：所谓身份效应可能部分来自对熟悉分布的偏好。
- **Do LLM Evaluators Prefer Themselves for a Reason?** — 2025-04-04，https://arxiv.org/abs/2504.03846 。它在数学、事实和代码等可验证任务上把“自身答案本来更正确”的合理偏好与有害自偏好分开；当 judge 自己的答案错误时仍有偏向，才是更强的有害证据。这补上本文摘要质量没有独立 ground truth 的缺口。
- **Play Favorites: A Statistical Method to Measure Self-Bias in LLM-as-a-Judge** — 2025-08-08，https://arxiv.org/abs/2508.06709 。该工作用独立第三方质量估计和统计模型控制候选质量，在 5,000 多个 prompt–completion 配对、专家人工判断与九个 judge 上区分 self-bias/family-bias。它把本文的互惠比较推进为显式质量校正。
- **Beyond the Surface: Measuring Self-Preference in LLM Judgments** — EMNLP 2025，https://aclanthology.org/2025.emnlp-main.86/ 。它引入 gold judgments 和 DBG 指标，比较 judge 对自身回答的评分与金标准，减少“自己的回答确实更好”这一混杂，并进一步分析风格、post-training 与 attention。
- **Are LLM Evaluators Really Narcissists? Sanity Checking Self-Preference Evaluations** — 2026-01-30，https://arxiv.org/abs/2601.22548 。该工作指出共享错误会造成假自偏好：judge 可能支持自己先前的错误答案，而不是偏爱身份。其 Evaluator Quality Baseline 报告可减少 89.6% 测量误差，在 37,448 个查询上复核后，初始显著结果只有 51% 仍显著。这是对本文因果措辞最直接的后续约束。
- **Quantifying and Mitigating Self-Preference Bias of LLM Judges** — 2026-04-24，https://arxiv.org/abs/2604.22891 。该工作构造近似等质量回答对，在 20 个模型上自动分离可辨别性与偏置倾向，并报告分维度评价平均降低 31.5% 的 SPB。它代表从“发现相关”走向“可规模化测量与缓解”，但等质量构造本身仍需独立验证。

这条研究脉络显示，本文最稳健的历史地位是：**它首次把 self-recognition 作为可干预变量，建立识别能力与自偏好的条件级关系；后续工作则逐步加入困惑度、可验证正确性、独立质量基线、共享错误和等质量配对，持续收紧“模型因为知道是自己写的而偏爱”的因果解释。** 因此不能把本文的线性相关直接写成已经证明的心理机制。

## 一句话判断

这篇论文的重要贡献不是证明 LLM 有“自我意识”，而是用角色互换、识别微调和控制任务说明：同源文本的可识别性会与 judge 的偏好系统性共同变化；但高顺序敏感性、缺少逐样本等质量金标准和后续发现的共享错误混杂意味着，它应被视为强机制线索，而不是 self-recognition 已被唯一确认为偏差原因。
